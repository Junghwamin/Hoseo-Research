실제 OpenAI 호출·실제 인스톨러 빌드가 필요한 것들이다.

## 실행 준비

```bash
cd "C:\Users\정화민\Desktop\Hoseo Reasearch\Hoseo-Research"
streamlit run report_app/app.py
```

브라우저에서 http://localhost:8501 접속. 각 항목 수행 후 `[ ]` → `[x]` 로 바꾸고
결과 열에 실제 관찰값을 적는다. 스크린샷은 `docs/qa_screens/` 에 저장한다.

## 기록 규칙

- 각 항목의 결과 열에는 **관찰한 값**을 적는다("정상" 대신 "1인당 61.4167").
- `[V##]` 표시가 있는 항목은 Phase 4 수정 후 다시 수행해 기대가 뒤집혔는지 확인한다.
- 재현되지 않은 항목은 결과 열에 "재현 안 됨 + 환경"을 적고 `docs/QA_REVIEW_REPORT.md` 에 반영한다.
